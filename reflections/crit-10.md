# Crit 10 reflection

**What was the breakthrough that moved the work forward?**

The password protection was not working, and my first instinct was that something in the browser was not going right, duplicate names, or a mismatched cookie. I checked both the local and the live production database directly, and both were completely clean, no duplicates, no inconsistency anywhere. That ruled out the thing I was expecting to find, which turned out to be the useful part: it meant the bug had to be in how a request got resolved, not in what was stored. The actual cause was that the server checked whoever's token was already attached to a request before it ever checked a correctly-supplied password, so a visitor whose browser held any stored token at all, even a stale, unrelated one from a completely different earlier visit, could never retrieve a different password-protected name, right password or not. Every automated test and every check was written had passed. None of them happened to try retrieving a password-protected name from a browser that already had some other token sitting in it, which is exactly the situation a real returning visitor is in most of the time.

**What did this work change about who I want to be as a software developer?**

Crit 9's reflection already said passing local tests does not mean an application works correctly in production, and this crit gave me a sharper version of that same lesson: a green check only tells you the scenarios you thought to write actually work, not that you thought of the right scenarios. The bug here was not hiding in some edge case I had missed by accident, it was hiding in the single most ordinary case, a returning visitor whose browser already remembers something, which I just never happened to test against a second, different, password-protected identity. I want to get better at asking what a real person's browser actually looks like when they show up, not just what a fresh test client looks like, because those two things quietly diverge in ways that are very easy to miss until someone runs into it for real.
